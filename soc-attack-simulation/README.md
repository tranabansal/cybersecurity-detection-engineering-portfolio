🛡️ SOC Attack Simulation Lab

> End-to-end simulation of a real-world cyber attack chain demonstrating SOC detection engineering, threat hunting, and incident response workflows.

---

👤 About This Project

This project simulates a realistic SOC environment where a multi-stage attack is detected, investigated, and documented using industry-standard tools and methodologies.

It demonstrates:
- Detection Engineering (Sigma + KQL)
- Threat Hunting (hypothesis-driven analysis)
- Incident Response (SOC workflow simulation)
- MITRE ATT&CK mapping

---

🎯 Objective

To replicate how a real Security Operations Center (SOC) would:

1. Detect malicious activity
2. Investigate security events
3. Correlate attack stages
4. Respond to incidents
5. Document findings
